# Flight Fare Prediction

## Project Overview
This project focuses on predicting flight ticket prices using Data Science and Machine Learning techniques.

## Objectives
- Analyze flight fare data.
- Perform data cleaning and exploratory data analysis (EDA).
- Identify factors affecting ticket prices.
- Build and evaluate machine learning models to predict flight fares.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Files
- `Flight_Fare_Prediction.ipynb` – Jupyter Notebook containing the project workflow.
- `flight-fare.zip` – Dataset archive, if included and permitted for public sharing.

## How to Run
1. Download or open the notebook in Google Colab.
2. Obtain the dataset and update the file path if necessary.
3. Run the notebook cells in order.
